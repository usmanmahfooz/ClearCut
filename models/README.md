# Model weights

The RMBG-1.4 quantized ONNX model is intentionally not committed to this repository. The Dockerfile downloads it while building the image.

For a native installation, review the model license first, then download the quantized ONNX file and save it as:

`models/model_quantized.onnx`

Model source and terms:
- https://huggingface.co/JCTN/RMBG-1.4/tree/main/onnx
- https://huggingface.co/briaai/RMBG-1.4
- https://bria.ai/bria-huggingface-model-license-agreement/

The model has a separate license from the ClearCut application code.
