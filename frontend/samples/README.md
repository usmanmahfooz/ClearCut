# Sample image assets

The six photographic PNG samples from the original development archive are not included in this repository export because the connected GitHub workflow used for this upload does not support binary file transfer.

To restore the original sample picker and preset library, copy these files from the original project archive into this directory:

- avatar-sample.png
- jewelry-sample.png
- packshot-sample.png
- pet-sample.png
- portrait-sample.png
- sneaker-sample.png

Background removal and image resizing do not require these optional images.
